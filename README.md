# Kapnanda Primary & Junior School Management System

A self-contained browser-based prototype covering PP1–Grade 9.

## Included
- Dashboard
- Learner register
- Teacher register
- Examinations
- Marks entry
- EE1–BE2 grading
- Subject ranking
- Overall learner ranking on reports
- Fees and fee payments
- Printable fee structure
- Basic timetable generator with class/teacher slot conflict prevention
- Attendance
- Individual colourful learner reports
- Bar and pie charts
- Automatic performance recommendation
- School/class performance analysis
- Settings
- JSON backup
- A4/browser printing

## How to use
Open `index.html` in a modern browser. Data is stored locally in the browser using localStorage.

## Important
This is a functional single-browser prototype, not yet a multi-user cloud/SMS/M-Pesa-connected production system. For a live school deployment, connect it to a secure database/backend, authentication, hosted file storage and a payment/SMS provider.
